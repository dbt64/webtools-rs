# Windows 桌面启动器设计

## 目标与范围

构建一款个人使用、仅面向 Windows 的桌面效率工具。第一版提供本地应用快速搜索与启动、常用网址和工具管理、可配置 AI 翻译，以及通过 Google Translate 网页翻译。搜索栏支持将 `?` 作为网页搜索指令前缀，输入 `?关键词` 后携带关键词跳转到当前选择的搜索平台（Google、百度或 Bilibili）。本地应用搜索支持中文、拼音、拼音首字母和英文名称。

第一版不实现通用插件市场；仅为翻译能力保留轻量扩展接口。网址和工具由用户手动维护。本地应用发现从 Windows 开始菜单快捷方式开始。收藏夹用于保存用户感兴趣的网址，并支持按文件夹整理。

## 技术方案

- Electron + Vue 3 + TypeScript，使用 Vite 构建渲染界面。
- Electron 主进程执行文件系统扫描、快捷方式解析、应用启动、外部网页打开、AI 网络请求及安全设置存取。
- Vue 渲染进程只通过受限 preload 暴露的、类型化 IPC 方法访问桌面能力；关闭 `nodeIntegration`，启用 `contextIsolation`。
- 中文拼音索引使用独立搜索适配层生成完整拼音和首字母，不把拼音库耦合进 UI 组件。
- AI 配置采用 OpenAI Chat Completions 兼容格式：可配置 base URL、模型名和 API Key，支持 OpenAI、DeepSeek 等兼容服务。API Key 使用 Windows Credential Manager 或 Electron safeStorage 加密后保存。

## 界面与交互

主窗口提供“搜索”“收藏夹”“网址与工具”“翻译”“设置”入口。搜索页面以输入框和分组结果为核心，分组显示应用、网址和工具。键盘上下键移动选择，回车执行，Escape 清空或返回。应用匹配其显示名、拼音、拼音首字母和英文别名；其他条目匹配名称及网址/描述。

输入以 `?` 开头时进入网页搜索模式，将前缀后的非空文本编码为 URL 参数并交给默认浏览器打开。设置页可选择 Google、百度或 Bilibili 为默认搜索平台。未配置默认平台时使用 Google。空查询不触发跳转。普通查询仍显示本地应用、网址和工具结果。

网址与工具页面支持新增、编辑、删除和打开。收藏夹页面支持新建、重命名、删除收藏夹，收藏网址支持打开、移出收藏夹和删除。搜索结果中的网址旁提供“+”按钮，点击后可选目标收藏夹，也可直接创建收藏夹；收藏页也提供通过粘贴 URL 新增收藏的入口。收藏条目自动尝试获取网站 favicon 并在列表中显示；抓取失败、无图标或网络不可用时使用网站域名首字母作为图标。图标抓取失败不阻止收藏，图标 URL 缓存到本机以减少重复请求。

翻译页面支持输入源文本、选择目标语言、调用 AI 翻译、复制译文，以及把文本带入 Google Translate 网页。AI 服务设置提供兼容 API 地址、模型、API Key 和连接测试；连接测试错误以可读提示显示，不在日志中输出密钥。

## 组件边界

- **主进程应用目录服务**：扫描用户和公共开始菜单目录中的 `.lnk`，解析显示名和目标，返回应用条目；合并去重并提供刷新能力。
- **主进程启动服务**：校验条目来源后启动应用或打开外部 URL；向调用方返回成功/失败结果。
- **搜索领域模块**：解析 `?` 命令、规范化查询、构建拼音索引并对应用/网址/工具排序；平台 URL 生成由搜索提供者适配器承担。
- **本地数据仓库**：持久化网址、工具、搜索平台偏好和非敏感设置；配置文件位于 Electron `app.getPath('userData')`。
- **收藏夹服务**：维护收藏夹和收藏网址的关联，添加收藏时尝试解析并缓存站点 favicon；网络抓取失败回退到基于域名的首字母图标。
- **AI 翻译服务**：封装 OpenAI 兼容 Chat Completions 请求、超时、错误转换和连接测试。密钥由主进程安全存取。
- **渲染界面**：搜索视图、条目管理视图、翻译视图和设置视图；不直接处理操作系统能力或密钥。

## 主要数据流

1. 启动时主进程扫描开始菜单快捷方式，并从用户数据目录加载网址、工具和偏好；结果经 preload 提供给 Vue。
2. 用户输入时渲染进程调用搜索模块。普通查询返回排序后的本地结果；`?关键词` 返回搜索模式与目标平台信息。
3. 用户确认网页搜索后，渲染进程调用主进程打开服务。主进程使用所选 provider 编码查询并打开最终 URL。
4. AI 翻译请求经 preload 发送到主进程；主进程取出密钥并请求兼容 API，仅把译文或清理过的错误返回界面。
5. Google Translate 翻译把文本编码进 Google Translate URL 并由默认浏览器打开，不要求 Google Cloud 凭据。
6. 添加收藏时，主进程以超时和响应大小限制请求目标网页，优先读取网页声明的 icon 链接，其次尝试 `/favicon.ico`；仅缓存可安全加载的图标地址或本地图标资源，不执行网页脚本。抓取结果失败或无效时保存条目并使用域名首字母回退图标。

## 错误处理

开始菜单目录缺失或某个快捷方式无法解析时跳过该项并允许其余扫描结果正常使用。应用目标失效时显示启动失败信息。无法打开浏览器时保留生成的 URL 并提示错误。AI 未配置时引导用户前往设置；网络超时、HTTP 错误和无效响应提供简明提示。密钥不得进入渲染日志或普通配置文件。

收藏夹图标抓取须设置超时和响应大小上限，并限制为 HTTP/HTTPS URL；遇到无图标、网络错误或无效响应时不影响保存收藏。收藏夹或收藏项删除前应明确目标，并在确认操作后更新本地关联数据。

## 验收要点

- 可扫描并启动开始菜单中的应用；搜索中文、完整拼音、首字母均能匹配中文应用名。
- 可新增、编辑、删除并打开网址和工具，数据重启后保留。
- 可创建和管理收藏夹；可从网址搜索结果点击“+”或粘贴 URL 添加收藏，并将其放入所选收藏夹。
- 收藏条目尽可能显示网站 favicon；图标抓取失败时显示域名首字母，收藏夹内容和图标信息重启后保留。
- `?关键词` 可按用户选择的 Google、百度或 Bilibili 平台打开正确编码的搜索 URL；空关键词不跳转。
- Google Translate 能在浏览器中打开并带上待翻译文本。
- OpenAI 兼容 API 配置可分别填写 URL、模型和密钥，支持 OpenAI/DeepSeek 配置；界面可调用翻译并显示可读错误。
- 渲染进程无法直接访问 Node.js；preload 只暴露必要的类型化能力。

## 测试策略

单元测试覆盖拼音检索与排序、`?` 命令解析、搜索 provider URL 编码、收藏夹归属与删除、favicon URL 解析/失败回退、设置数据校验和 AI 请求/错误映射。集成测试覆盖 preload IPC 与主进程服务、快捷方式目录扫描（使用临时夹具）、收藏数据和图标缓存持久化。手动验收覆盖 Windows 开始菜单扫描、应用启动、默认浏览器跳转、收藏网址及图标/首字母回退、凭据保存及实际 AI 服务连通。
